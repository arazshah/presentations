Wireframe (SVG)

نمایش ساختار کلی صفحه به صورت شماتیک. مناسب برای:

  • ✓ درک سریع چیدمان صفحه
  • ✓ ارائه به ذینفعان پروژه
  • ✓ مبنای طراحی در Figma

HTML + Tailwind CSS

کد کامل و آماده اجرا با استایل‌های Tailwind. مناسب برای:

  • ✓ پیش‌نمایش سریع در مرورگر
  • ✓ پروژه‌های ساده بدون فریمورک
  • ✓ مبنای تبدیل به فریمورک دلخواه

React + TypeScript

کامپوننت‌های React با TypeScript و Tailwind. مناسب برای:

  • ✓ استفاده مستقیم در پروژه React
  • ✓ Type Safety با TypeScript
  • ✓ کامپوننت‌های قابل استفاده مجدد

📦 شامل: Page Component، Sub-components، Types، Index file

Dashboard.tsx 
import React from 'react';
import { EmployeeTable } from './components';
import { Employee } from './types';

interface DashboardProps {
  employees: Employee[];
}

export const Dashboard: React.FC<DashboardProps> = ({
  employees
}) => {
  return (
    <div className="min-h-screen">
      {/* هدر */}
      <Header />
      
      {/* محتوای اصلی */}
      <main className="p-6">
        <EmployeeTable 
          data={employees}
        />
      </main>
    </div>
  );
};

سوالات متداول

پرسش‌های رایج

بله، تمام خروجی‌ها کاملاً قابل ویرایش هستند. کد HTML و React را می‌توانید مستقیماً در IDE ویرایش کنید. فایل Figma JSON را می‌توانید در Figma import کرده و تغییر دهید. Wireframe به صورت SVG است که در هر نرم‌افزار گرافیکی قابل ویرایش است.

کد تولید شده از best practices پیروی می‌کند: TypeScript برای type safety، Tailwind برای استایل‌های consistent، کامپوننت‌های قابل استفاده مجدد، و کامنت‌های فارسی برای درک بهتر. البته ممکن است نیاز به بهینه‌سازی برای production داشته باشد.

بله، می‌توانید رنگ‌بندی برند، فونت‌ها و استایل‌های خاص پروژه را تعریف کنید. سیستم این تنظیمات را در تولید خروجی اعمال می‌کند. همچنین امکان تعریف کامپوننت‌های پایه وجود دارد.

ایده‌ها فقط برای پردازش به Claude API ارسال می‌شوند و ذخیره نمی‌شوند. Anthropic (سازنده Claude) تعهد به حفظ حریم خصوصی دارد. همچنین امکان deploy روی سرور داخلی وجود دارد.

بله، برای ارتباط با Claude API نیاز به اینترنت است. اما خروجی‌های تولید شده به صورت فایل ذخیره می‌شوند و برای استفاده نیاز به اینترنت ندارند.
