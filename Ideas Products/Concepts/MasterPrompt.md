## 📤 خروجی مورد انتظار
یک فایل HTML کامل و مستقل که:
1. بدون نیاز به فایل خارجی کار کند (self-contained)
2. از CDN برای Tailwind و فونت‌ها استفاده کند
3. کد JavaScript تعاملات داخل فایل باشد
4. کامنت‌گذاری مناسب برای بخش‌های مختلف داشته باشد
5. قابل ویرایش و توسعه باشد
