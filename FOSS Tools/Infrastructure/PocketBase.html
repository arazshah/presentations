معرفی PocketBase

Backend کامل در یک فایل

🎯 PocketBase چیست؟

PocketBase یک Backend متن‌باز است که به زبان Go نوشته شده و تمام قابلیت‌های مورد نیاز یک اپلیکیشن را در یک فایل اجرایی ارائه می‌دهد. این پروژه توسط Gani Georgiev توسعه داده شده و به سرعت به یکی از محبوب‌ترین جایگزین‌های Firebase تبدیل شده است.

🗃️

SQLite Database

دیتابیس embedded با SQLite. بدون نیاز به نصب سرور جداگانه. سریع، قابل اعتماد و پرتابل.

🔌

REST API خودکار

برای هر Collection به صورت خودکار REST API ایجاد می‌شود. CRUD کامل با فیلتر، مرتب‌سازی و صفحه‌بندی.

🔐

احراز هویت کامل

Email/Password، OAuth2 (Google, GitHub, ...)، JWT tokens و مدیریت کاربران.

📁

ذخیره فایل

آپلود و مدیریت فایل‌ها با پشتیبانی از S3. تولید خودکار thumbnail برای تصاویر.

⚡

Realtime

اشتراک‌گذاری تغییرات به صورت لحظه‌ای با SSE. مناسب برای چت، نوتیفیکیشن و...

پنل مدیریت زیبا و کامل برای مدیریت داده‌ها، کاربران و تنظیمات.

Collections و Schema

ساختار داده در PocketBase

📦 Collection چیست؟

Collection در PocketBase معادل جدول (Table) در دیتابیس‌های رابطه‌ای است. هر Collection شامل فیلدها (Schema) و قوانین دسترسی (Rules) است.

انواع Collection

نوع توضیح کاربرد
Base Collection عمومی برای ذخیره داده محصولات، پست‌ها، سفارشات
Auth Collection با قابلیت احراز هویت کاربران، ادمین‌ها
View Collection فقط خواندنی بر اساس SQL query گزارش‌ها، آمار، داده‌های ترکیبی

🏗️ انواع فیلدها

نوع فیلد توضیح گزینه‌ها
text متن کوتاه min, max, pattern
editor متن بلند با Rich Text convertUrls
number عدد صحیح یا اعشاری min, max, noDecimal
bool بولین (true/false) -
email آدرس ایمیل exceptDomains, onlyDomains
url آدرس URL exceptDomains, onlyDomains
date تاریخ و زمان min, max
select انتخاب از لیست values, maxSelect
json داده JSON maxSize
file فایل آپلودی maxSelect, maxSize, mimeTypes, thumbs
relation رابطه با Collection دیگر collectionId, cascadeDelete, maxSelect

🔐 قوانین دسترسی (API Rules)

قوانین دسترسی تعیین می‌کنند چه کسی می‌تواند چه عملیاتی روی داده‌ها انجام دهد. از یک زبان فیلتر ساده استفاده می‌شود.

TXT
API Rules Examples 
═══════════════════════════════════════════════════════════
متغیرهای موجود
═══════════════════════════════════════════════════════════

@request.auth         کاربر لاگین شده
@request.auth.id      آیدی کاربر لاگین شده
@request.data         داده ارسال شده در درخواست
@collection           رکورد فعلی

═══════════════════════════════════════════════════════════
مثال‌های قوانین
═══════════════════════════════════════════════════════════

# خالی = فقط ادمین
""

# همه می‌توانند
null
یا
""  (با تیک Allow در Admin UI)

# فقط کاربران لاگین شده
@request.auth.id != ""

# فقط صاحب رکورد
@request.auth.id = user.id

# فقط رکوردهای منتشر شده یا صاحب
published = true || @request.auth.id = author.id

# بررسی نقش کاربر (با فرض فیلد role در users)
@request.auth.role = "admin"

# بررسی عضویت در لیست
@request.auth.id ?= members.id

# ترکیب شرایط
(@request.auth.id = owner.id) || (@request.auth.role = "moderator")

# محدود کردن فیلدهای قابل ویرایش
@request.data.role:isset = false

# بررسی رابطه
@request.auth.id = team.members.id

🔍 پارامترهای Query

پارامتر توضیح مثال
page شماره صفحه ?page=2
perPage تعداد در هر صفحه (حداکثر ۵۰۰) ?perPage=50
sort مرتب‌سازی (- برای نزولی) ?sort=-created,title
filter فیلتر کردن نتایج ?filter=(status='active')
expand بارگذاری روابط ?expand=author,comments
fields انتخاب فیلدها ?fields=id,title,author
skipTotal عدم شمارش کل (سریع‌تر) ?skipTotal=1

pocketbase_client.js 
// ═══════════════════════════════════════════════════════════
// نصب
// ═══════════════════════════════════════════════════════════

// npm install pocketbase
// یا
// yarn add pocketbase

// ═══════════════════════════════════════════════════════════
// راه‌اندازی
// ═══════════════════════════════════════════════════════════

import PocketBase from 'pocketbase';

const pb = new PocketBase('http://127.0.0.1:8090');

// ═══════════════════════════════════════════════════════════
// CRUD Operations
// ═══════════════════════════════════════════════════════════

// دریافت لیست
const posts = await pb.collection('posts').getList(1, 20, {
    filter: 'published = true',
    sort: '-created',
    expand: 'author',
});

console.log(posts.items);       // آرایه رکوردها
console.log(posts.totalItems);  // تعداد کل
console.log(posts.totalPages);  // تعداد صفحات

// دریافت همه (با احتیاط استفاده کنید)
const allPosts = await pb.collection('posts').getFullList({
    sort: '-created',
});

// دریافت اولین نتیجه
const firstPost = await pb.collection('posts').getFirstListItem(
    'slug="hello-world"',
    { expand: 'author' }
);

// دریافت با آیدی
const post = await pb.collection('posts').getOne('RECORD_ID', {
    expand: 'author,comments_via_post',
});

// ایجاد رکورد
const newPost = await pb.collection('posts').create({
    title: 'My New Post',
    content: 'This is the content...',
    author: pb.authStore.model.id,
    published: false,
});

// بروزرسانی
const updatedPost = await pb.collection('posts').update('RECORD_ID', {
    title: 'Updated Title',
    published: true,
});

// حذف
await pb.collection('posts').delete('RECORD_ID');

async function startOAuth2(provider) {
    const authMethods = await pb.collection('users').listAuthMethods();
    const providerData = authMethods.authProviders.find(
        p => p.name === provider
    );
    
    // ذخیره state برای verification
    localStorage.setItem('oauth2_state', providerData.state);
    localStorage.setItem('oauth2_verifier', providerData.codeVerifier);
    
    // redirect
    window.location.href = providerData.authUrl + 
        '&redirect_uri=' + encodeURIComponent(window.location.origin + '/oauth-callback');
}

// مرحله 2: در callback page
async function handleOAuth2Callback() {
    const params = new URLSearchParams(window.location.search);
    const code = params.get('code');
    const state = params.get('state');
    
    const savedState = localStorage.getItem('oauth2_state');
    const codeVerifier = localStorage.getItem('oauth2_verifier');
    
    if (state !== savedState) {
        throw new Error('Invalid state');
    }
    
    const authData = await pb.collection('users').authWithOAuth2Code(
        'google',
        code,
        codeVerifier,
        window.location.origin + '/oauth-callback'
    );
    
    // پاکسازی
    localStorage.removeItem('oauth2_state');
    localStorage.removeItem('oauth2_verifier');
    
    return authData;
}

    return new Promise((resolve, reject) => {
        const xhr = new XMLHttpRequest();
        const formData = new FormData();
        formData.append('file', file);
        
        xhr.upload.addEventListener('progress', (e) => {
            if (e.lengthComputable) {
                const percent = (e.loaded / e.total) * 100;
                onProgress(percent);
            }
        });
        
        xhr.addEventListener('load', () => {
            if (xhr.status >= 200 && xhr.status < 300) {
                resolve(JSON.parse(xhr.responseText));
            } else {
                reject(new Error(xhr.statusText));
            }
        });
        
        xhr.addEventListener('error', () => reject(new Error('Upload failed')));
        
        xhr.open('POST', `${pb.baseUrl}/api/collections/uploads/records`);
        xhr.setRequestHeader('Authorization', `Bearer ${pb.authStore.token}`);
        xhr.send(formData);
    });
}

        this.messages = [];
    }

        const result = await this.pb.collection('messages').getList(1, 50, {
            filter: `room = "${this.roomId}"`,
            sort: 'created',
            expand: 'sender',
        });
        
        this.messages = result.items;
        this.renderMessages();
    }
    
    // اشتراک در پیام‌های جدید
    subscribeToMessages() {
        this.pb.collection('messages').subscribe('*', (e) => {
            // فقط پیام‌های این اتاق
            if (e.record.room !== this.roomId) return;
            
            switch (e.action) {
                case 'create':
                    this.messages.push(e.record);
                    this.renderNewMessage(e.record);
                    this.scrollToBottom();
                    break;
                case 'update':
                    const index = this.messages.findIndex(m => m.id === e.record.id);
                    if (index !== -1) {
                        this.messages[index] = e.record;
                        this.updateMessageInUI(e.record);
                    }
                    break;
                case 'delete':
                    this.messages = this.messages.filter(m => m.id !== e.record.id);
                    this.removeMessageFromUI(e.record.id);
                    break;
            }
        });
    }
    
    // ارسال پیام
    async sendMessage(text) {
        if (!text.trim()) return;
        
        const message = await this.pb.collection('messages').create({
            text: text,
            room: this.roomId,
            sender: this.pb.authStore.model.id,
        });
        
        return message;
    }
    
    // ویرایش پیام
    async editMessage(messageId, newText) {
        const message = await this.pb.collection('messages').update(messageId, {
            text: newText,
            edited: true,
        });
        return message;
    }
    
    // حذف پیام
    async deleteMessage(messageId) {
        await this.pb.collection('messages').delete(messageId);
    }
    
    // رندر پیام‌ها
    renderMessages() {
        const container = document.getElementById('messages');
        container.innerHTML = this.messages.map(m => this.messageHTML(m)).join('');
        this.scrollToBottom();
    }
    
    renderNewMessage(message) {
        const container = document.getElementById('messages');
        container.insertAdjacentHTML('beforeend', this.messageHTML(message));
    }
    
    messageHTML(message) {
        const isOwn = message.sender === this.pb.authStore.model?.id;
        return `
            <div class="message ${isOwn ? 'own' : ''}" data-id="${message.id}">
                <div class="message-sender">${message.expand?.sender?.name || 'Unknown'}</div>
                <div class="message-text">${message.text}</div>
                <div class="message-time">${new Date(message.created).toLocaleTimeString()}</div>
                ${message.edited ? '<span class="edited">(edited)</span>' : ''}
            </div>
        `;
    }
    
    scrollToBottom() {
        const container = document.getElementById('messages');
        container.scrollTop = container.scrollHeight;
    }
    
    // پاکسازی
    destroy() {
        this.pb.collection('messages').unsubscribe('*');
    }
}

function useRealtimeCollection(collectionName, options = {}) {
    const [records, setRecords] = useState([]);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);
    
    const { filter, sort, expand } = options;
    
    // بارگذاری اولیه
    useEffect(() => {
        async function loadData() {
            try {
                setLoading(true);
                const result = await pb.collection(collectionName).getFullList({
                    filter,
                    sort,
                    expand,
                });
                setRecords(result);
            } catch (err) {
                setError(err);
            } finally {
                setLoading(false);
            }
        }
        
        loadData();
    }, [collectionName, filter, sort, expand]);
    
    // اشتراک در تغییرات
    useEffect(() => {
        pb.collection(collectionName).subscribe('*', (e) => {
            setRecords(current => {
                switch (e.action) {
                    case 'create':
                        return [...current, e.record];
                    case 'update':
                        return current.map(r => 
                            r.id === e.record.id ? e.record : r
                        );
                    case 'delete':
                        return current.filter(r => r.id !== e.record.id);
                    default:
                        return current;
                }
            });
        });
        
        return () => {
            pb.collection(collectionName).unsubscribe('*');
        };
    }, [collectionName]);
    
    return { records, loading, error };
}

function useRealtimeRecord(collectionName, recordId) {
    const [record, setRecord] = useState(null);
    const [loading, setLoading] = useState(true);
    
    useEffect(() => {
        if (!recordId) return;
        
        // بارگذاری اولیه
        pb.collection(collectionName).getOne(recordId)
            .then(setRecord)
            .finally(() => setLoading(false));
        
        // اشتراک
        pb.collection(collectionName).subscribe(recordId, (e) => {
            if (e.action === 'delete') {
                setRecord(null);
            } else {
                setRecord(e.record);
            }
        });
        
        return () => {
            pb.collection(collectionName).unsubscribe(recordId);
        };
    }, [collectionName, recordId]);
    
    return { record, loading };
}

    // ═══════════════════════════════════════════════════════════
    
    app.OnBeforeServe().Add(func(e *core.ServeEvent) error {
        e.Router.Use(func(next echo.HandlerFunc) echo.HandlerFunc {
            return func(c echo.Context) error {
                // لاگ همه درخواست‌ها
                log.Printf("%s %s", c.Request().Method, c.Request().URL.Path)
                return next(c)
            }
        })
        return nil
    })

    // اجرای اپلیکیشن
    if err := app.Start(); err != nil {
        log.Fatal(err)
    }
}

deploy_vps.sh 
#!/bin/bash
# استقرار PocketBase روی Ubuntu VPS

# ═══════════════════════════════════════════════════════════
# 1. آماده‌سازی سرور
# ═══════════════════════════════════════════════════════════

# بروزرسانی سیستم
sudo apt update && sudo apt upgrade -y

# نصب ابزارهای ضروری
sudo apt install -y wget unzip ufw nginx certbot python3-certbot-nginx

# ایجاد کاربر برای PocketBase
sudo useradd -r -s /bin/false pocketbase

# ═══════════════════════════════════════════════════════════
# 2. دانلود و نصب PocketBase
# ═══════════════════════════════════════════════════════════

# ایجاد دایرکتوری
sudo mkdir -p /opt/pocketbase
cd /opt/pocketbase

# دانلود آخرین نسخه
PB_VERSION="0.22.0"
wget https://github.com/pocketbase/pocketbase/releases/download/v${PB_VERSION}/pocketbase_${PB_VERSION}_linux_amd64.zip
unzip pocketbase_${PB_VERSION}_linux_amd64.zip
rm pocketbase_${PB_VERSION}_linux_amd64.zip

# تنظیم مالکیت
sudo chown -R pocketbase:pocketbase /opt/pocketbase

# ═══════════════════════════════════════════════════════════
# 3. ایجاد Systemd Service
# ═══════════════════════════════════════════════════════════

sudo tee /etc/systemd/system/pocketbase.service > /dev/null <<EOF
[Unit]
Description=PocketBase
After=network.target

[Service]
Type=simple
User=pocketbase
Group=pocketbase
WorkingDirectory=/opt/pocketbase
ExecStart=/opt/pocketbase/pocketbase serve --http=127.0.0.1:8090
Restart=always
RestartSec=5
StandardOutput=append:/var/log/pocketbase/access.log
StandardError=append:/var/log/pocketbase/error.log

# Security
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/opt/pocketbase/pb_data

[Install]
WantedBy=multi-user.target
EOF

# ایجاد دایرکتوری لاگ
sudo mkdir -p /var/log/pocketbase
sudo chown pocketbase:pocketbase /var/log/pocketbase

# فعال‌سازی و شروع سرویس
sudo systemctl daemon-reload
sudo systemctl enable pocketbase
sudo systemctl start pocketbase

# بررسی وضعیت
sudo systemctl status pocketbase

# ═══════════════════════════════════════════════════════════
# 4. تنظیم Nginx Reverse Proxy
# ═══════════════════════════════════════════════════════════

sudo tee /etc/nginx/sites-available/pocketbase > /dev/null <<EOF
server {
    listen 80;
    server_name api.example.com;
    
    client_max_body_size 100M;
    
    location / {
        proxy_pass http://127.0.0.1:8090;
        proxy_http_version 1.1;
        proxy_set_header Upgrade \$http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host \$host;
        proxy_set_header X-Real-IP \$remote_addr;
        proxy_set_header X-Forwarded-For \$proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto \$scheme;
        
        # SSE support
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 86400s;
    }
}
EOF

# فعال‌سازی سایت
sudo ln -s /etc/nginx/sites-available/pocketbase /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

# ═══════════════════════════════════════════════════════════
# 5. تنظیم SSL با Let's Encrypt
# ═══════════════════════════════════════════════════════════

sudo certbot --nginx -d api.example.com

# ═══════════════════════════════════════════════════════════
# 6. تنظیم فایروال
# ═══════════════════════════════════════════════════════════

sudo ufw allow 22/tcp   # SSH
sudo ufw allow 80/tcp   # HTTP
sudo ufw allow 443/tcp  # HTTPS
sudo ufw enable

# ═══════════════════════════════════════════════════════════
# 7. تنظیم بکاپ خودکار
# ═══════════════════════════════════════════════════════════

sudo tee /opt/pocketbase/backup.sh > /dev/null <<'EOF'
#!/bin/bash
BACKUP_DIR="/opt/pocketbase/backups"
DATE=$(date +%Y%m%d_%H%M%S)
mkdir -p $BACKUP_DIR

# بکاپ دیتابیس و فایل‌ها
tar -czf $BACKUP_DIR/pb_backup_$DATE.tar.gz pb_data

# نگهداری 7 روز اخیر
find $BACKUP_DIR -type f -mtime +7 -delete

# آپلود به S3 (اختیاری)
# aws s3 cp $BACKUP_DIR/pb_backup_$DATE.tar.gz s3://your-bucket/backups/
EOF

sudo chmod +x /opt/pocketbase/backup.sh

# اضافه کردن به cron (هر روز ساعت 3 صبح)
echo "0 3 * * * /opt/pocketbase/backup.sh" | sudo crontab -u pocketbase -
