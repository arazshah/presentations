پلتفرم متن‌باز مدیریت داده‌های مکانی

🤔 GeoNode چیست؟

GeoNode یک سامانه مدیریت محتوای مکانی (Geospatial Content Management System) متن‌باز است که بر پایه Django ساخته شده و امکان آپلود، مدیریت، اشتراک‌گذاری و انتشار داده‌های جغرافیایی (وکتور و رستر) را فراهم می‌کند.

GeoNode به عنوان یک زیرساخت داده مکانی (SDI — Spatial Data Infrastructure) عمل می‌کند و از استانداردهای بین‌المللی OGC (Open Geospatial Consortium) پشتیبانی می‌کند.

💡

به زبان ساده

GeoNode مثل WordPress است اما برای داده‌های مکانی. همانطور که WordPress مدیریت مطالب وب را آسان می‌کند، GeoNode مدیریت لایه‌های نقشه، نقشه‌های تعاملی و فراداده‌های مکانی را ساده می‌کند.

🎯 قابلیت‌های اصلی

📤

آپلود داده

آپلود آسان Shapefile, GeoTIFF, GeoJSON, KML, CSV و ده‌ها فرمت دیگر. پردازش خودکار و انتشار به عنوان سرویس وب.

🗺️

ساخت نقشه

ساخت نقشه‌های تعاملی با ترکیب لایه‌های مختلف. ابزار MapStore 2 با قابلیت‌های پیشرفته.

📋

فراداده (Metadata)

مدیریت فراداده مطابق استاندارد ISO 19115. جستجوی پیشرفته و کاتالوگ CSW.

🔗

سرویس‌های OGC

WMS, WFS, WCS, WMTS, CSW. سازگار با تمام نرم‌افزارهای GIS.

👥

مدیریت کاربران

سیستم مجوزدهی پیشرفته. نقش‌ها و گروه‌ها. کنترل دسترسی در سطح لایه و نقشه.

🔌

API کامل

REST API برای تمام عملیات. GraphQL (اختیاری). یکپارچه‌سازی با سیستم‌های دیگر.

🐍

Django (هسته)

فریم‌ورک وب پایتون. هسته GeoNode شامل:
• مدیریت لایه‌ها و نقشه‌ها
• سیستم کاربران و مجوزها
• REST API (DRF)
• فراداده و جستجو

🗺️

GeoServer

سرور مکانی Java-based. مسئول:
• ارائه سرویس‌های OGC
• رندر نقشه (WMS)
• دسترسی به فیچرها (WFS)
• استایل‌دهی (SLD)

🎨

MapStore 2

کلاینت نقشه مبتنی بر React:
• نقشه‌ساز تعاملی
• ویرایشگر استایل بصری
• ابزارهای اندازه‌گیری
• داشبورد و GeoStory

🗄️

PostgreSQL + PostGIS

پایگاه داده اصلی:
• ذخیره داده‌های وکتور
• فراداده و تنظیمات
• کوئری‌های مکانی
• اطلاعات کاربران

📋

pyCSW

سرور کاتالوگ مکانی:
• استاندارد OGC CSW
• جستجوی فراداده
• Harvesting از منابع دیگر
• ISO 19115 / Dublin Core

⏰

Celery + Redis

پردازش غیرهمزمان:
• آپلود و پردازش فایل‌ها
• تولید Thumbnail
• همگام‌سازی با GeoServer
• وظایف زمان‌بندی‌شده

dev-install.sh 
#!/bin/bash
# ═══════════════════════════════════════════════════════════
# نصب GeoNode برای توسعه (بدون Docker)
# Ubuntu 22.04 LTS
# ═══════════════════════════════════════════════════════════

# 1. نصب پیش‌نیازها
sudo apt update
sudo apt install -y \
    python3.10 python3.10-venv python3.10-dev \
    build-essential gcc g++ \
    libpq-dev libgdal-dev libgeos-dev libproj-dev \
    postgresql postgresql-contrib postgis \
    openjdk-11-jdk \
    git curl wget unzip

# 2. تنظیم PostgreSQL
sudo -u postgres psql -c "CREATE USER geonode WITH PASSWORD 'geonode';"
sudo -u postgres psql -c "CREATE DATABASE geonode OWNER geonode;"
sudo -u postgres psql -c "CREATE DATABASE geonode_data OWNER geonode;"
sudo -u postgres psql -d geonode -c "CREATE EXTENSION postgis;"
sudo -u postgres psql -d geonode_data -c "CREATE EXTENSION postgis;"
sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE geonode TO geonode;"
sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE geonode_data TO geonode;"

# 3. نصب GeoServer
GEOSERVER_VERSION=2.24.2
wget "https://sourceforge.net/projects/geoserver/files/GeoServer/${GEOSERVER_VERSION}/geoserver-${GEOSERVER_VERSION}-bin.zip"
unzip geoserver-${GEOSERVER_VERSION}-bin.zip -d /opt/
export GEOSERVER_HOME=/opt/geoserver-${GEOSERVER_VERSION}

# 4. کلون و نصب GeoNode
git clone https://github.com/GeoNode/geonode.git -b 4.2.x
cd geonode

# ایجاد محیط مجازی
python3.10 -m venv venv
source venv/bin/activate

# نصب وابستگی‌ها
pip install --upgrade pip setuptools wheel
pip install -e ".[dev,test]"
pip install pygdal=="$(gdal-config --version).*"

# 5. پیکربندی
cp geonode/local_settings.py.sample geonode/local_settings.py
nano geonode/local_settings.py

# 6. مهاجرت و راه‌اندازی
python manage.py migrate
python manage.py collectstatic --noinput
python manage.py createsuperuser

# 7. اجرای سرور توسعه
python manage.py runserver 0.0.0.0:8000

# در ترمینال دیگر: اجرای GeoServer
cd $GEOSERVER_HOME/bin
./startup.sh

"""
آپلود داده‌ها به GeoNode با REST API
"""

import requests
import os
from pathlib import Path


class GeoNodeClient:
    """کلاینت ساده برای ارتباط با GeoNode API"""
    
    def __init__(self, base_url: str, username: str, password: str):
        self.base_url = base_url.rstrip('/')
        self.session = requests.Session()
        self.session.auth = (username, password)
        
        # دریافت CSRF token
        self.session.get(f"{self.base_url}/")
        csrf = self.session.cookies.get('csrftoken', '')
        self.session.headers.update({
            'X-CSRFToken': csrf,
            'Referer': self.base_url,
        })
    
    def upload_layer(self, file_path: str, 
                     layer_name: str = None,
                     charset: str = 'UTF-8',
                     permissions: dict = None) -> dict:
        """
        آپلود یک لایه (Shapefile ZIP, GeoTIFF, GeoJSON, ...)
        
        Parameters
        ----------
        file_path : مسیر فایل
        layer_name : نام لایه (اختیاری)
        charset : کدگذاری کاراکتر
        permissions : دسترسی‌ها
        
        Returns
        -------
        اطلاعات لایه آپلودشده
        """
        file_path = Path(file_path)
        
        if not file_path.exists():
            raise FileNotFoundError(f"فایل یافت نشد: {file_path}")
        
        if layer_name is None:
            layer_name = file_path.stem
        
        url = f"{self.base_url}/api/v2/uploads/upload/"
        
        # آماده‌سازی فایل
        with open(file_path, 'rb') as f:
            files = {
                'base_file': (file_path.name, f, 'application/octet-stream'),
            }
            
            data = {
                'charset': charset,
                'dataset_title': layer_name,
                'time': 'false',
                'mosaic': 'false',
            }
            
            if permissions:
                data['permissions'] = str(permissions)
            
            response = self.session.post(url, files=files, data=data)
        
        if response.status_code in (200, 201):
            result = response.json()
            print(f"✅ لایه '{layer_name}' با موفقیت آپلود شد")
            return result
        else:
            print(f"❌ خطا در آپلود: {response.status_code}")
            print(response.text)
            return None
    
    def list_datasets(self, page: int = 1, 
                      page_size: int = 20) -> dict:
        """لیست لایه‌ها"""
        url = f"{self.base_url}/api/v2/datasets/"
        params = {
            'page': page,
            'page_size': page_size,
        }
        response = self.session.get(url, params=params)
        return response.json()
    
    def get_dataset(self, pk: int) -> dict:
        """دریافت اطلاعات یک لایه"""
        url = f"{self.base_url}/api/v2/datasets/{pk}/"
        response = self.session.get(url)
        return response.json()
    
    def delete_dataset(self, pk: int) -> bool:
        """حذف یک لایه"""
        url = f"{self.base_url}/api/v2/datasets/{pk}/"
        response = self.session.delete(url)
        if response.status_code == 204:
            print(f"✅ لایه {pk} حذف شد")
            return True
        return False
    
    def update_metadata(self, pk: int, metadata: dict) -> dict:
        """به‌روزرسانی فراداده لایه"""
        url = f"{self.base_url}/api/v2/datasets/{pk}/"
        response = self.session.patch(url, json=metadata)
        return response.json()
    
    def search(self, query: str, 
               resource_type: str = None) -> dict:
        """جستجو در منابع"""
        url = f"{self.base_url}/api/v2/resources/"
        params = {'search': query}
        if resource_type:
            params['filter{resource_type}'] = resource_type
        
        response = self.session.get(url, params=params)
        return response.json()
    
    def create_map(self, title: str, 
                   layers: list, 
                   abstract: str = '') -> dict:
        """ایجاد نقشه جدید"""
        url = f"{self.base_url}/api/v2/maps/"
        data = {
            'title': title,
            'abstract': abstract,
            'maplayers': layers,
        }
        response = self.session.post(url, json=data)
        return response.json()

"""
به‌روزرسانی دسته‌ای فراداده لایه‌ها در GeoNode
"""

import requests
import json
from datetime import datetime


def batch_update_metadata(base_url: str, auth: tuple, updates: list):
    """
    به‌روزرسانی دسته‌ای فراداده
    
    Parameters
    ----------
    base_url : آدرس GeoNode
    auth : (username, password)
    updates : لیست دیکشنری‌ها با pk و فراداده
    """
    session = requests.Session()
    session.auth = auth
    
    for update in updates:
        pk = update.pop('pk')
        url = f"{base_url}/api/v2/datasets/{pk}/"
        
        response = session.patch(url, json=update)
        
        if response.status_code == 200:
            print(f"✅ لایه {pk}: فراداده به‌روز شد")
        else:
            print(f"❌ لایه {pk}: خطا — {response.status_code}")


def export_metadata_csv(base_url: str, auth: tuple, output_file: str):
    """
    خروجی گرفتن فراداده تمام لایه‌ها به CSV
    """
    import csv
    
    session = requests.Session()
    session.auth = auth
    
    url = f"{base_url}/api/v2/datasets/"
    all_datasets = []
    page = 1
    
    while True:
        response = session.get(url, params={'page': page, 'page_size': 50})
        data = response.json()
        all_datasets.extend(data.get('datasets', []))
        
        if not data.get('links', {}).get('next'):
            break
        page += 1
    
    with open(output_file, 'w', newline='', encoding='utf-8') as f:
        writer = csv.writer(f)
        writer.writerow([
            'pk', 'title', 'abstract', 'category',
            'keywords', 'date', 'owner', 'subtype'
        ])
        
        for ds in all_datasets:
            writer.writerow([
                ds.get('pk'),
                ds.get('title'),
                ds.get('abstract', ''),
                ds.get('category', {}).get('identifier', ''),
                ', '.join(ds.get('keywords', [])),
                ds.get('date'),
                ds.get('owner', {}).get('username', ''),
                ds.get('subtype'),
            ])
    
    print(f"✅ فراداده {len(all_datasets)} لایه به {output_file} خروجی گرفته شد")

"""
مثال‌های کامل استفاده از GeoNode API و سرویس‌های OGC
"""

import requests
from owslib.wms import WebMapService
from owslib.wfs import WebFeatureService
from owslib.csw import CatalogueServiceWeb
import json

GEONODE_URL = "http://localhost"
GEOSERVER_URL = f"{GEONODE_URL}/geoserver/ows"
AUTH = ("admin", "admin")


# ═══════════════════════════════════════════════════════════
# 1. REST API
# ═══════════════════════════════════════════════════════════

def api_list_datasets():
    """لیست لایه‌ها با فیلتر و مرتب‌سازی"""
    url = f"{GEONODE_URL}/api/v2/datasets/"
    
    params = {
        'page_size': 10,
        'page': 1,
        'order_by': '-date',  # جدیدترین
        'filter{{subtype}}': 'vector',  # فقط وکتور
    }
    
    response = requests.get(url, params=params, auth=AUTH)
    data = response.json()
    
    print(f"تعداد کل: {data['total']}")
    for ds in data['datasets']:
        print(f"  [{ds['pk']}] {ds['title']} — {ds['subtype']}")
    
    return data


def api_spatial_search():
    """جستجوی مکانی (داخل یک bbox)"""
    url = f"{GEONODE_URL}/api/v2/datasets/"
    
    # bbox: [minLon, minLat, maxLon, maxLat]
    # محدوده ایران
    params = {
        'page_size': 50,
        'extent': '44.0,25.0,63.5,39.8',  # ایران
    }
    
    response = requests.get(url, params=params, auth=AUTH)
    return response.json()


# ═══════════════════════════════════════════════════════════
# 2. WMS — دریافت تصویر نقشه
# ═══════════════════════════════════════════════════════════

def wms_get_map():
    """دریافت تصویر نقشه از WMS"""
    wms = WebMapService(GEOSERVER_URL, version='1.1.1')
    
    # لیست لایه‌ها
    print("لایه‌های WMS:")
    for layer_name in list(wms.contents)[:10]:
        layer = wms[layer_name]
        print(f"  {layer_name}: {layer.title}")
    
    # دریافت تصویر
    img = wms.getmap(
        layers=['geonode:iran_provinces'],
        srs='EPSG:4326',
        bbox=(44.0, 25.0, 63.5, 39.8),
        size=(800, 600),
        format='image/png',
        transparent=True,
    )
    
    with open('iran_map.png', 'wb') as f:
        f.write(img.read())
    
    print("✅ تصویر نقشه ذخیره شد: iran_map.png")


# ═══════════════════════════════════════════════════════════
# 3. WFS — دریافت داده‌های وکتور
# ═══════════════════════════════════════════════════════════

def wfs_get_features():
    """دریافت فیچرها از WFS"""
    wfs = WebFeatureService(GEOSERVER_URL, version='2.0.0')
    
    # لیست لایه‌ها
    print("\nلایه‌های WFS:")
    for layer_name in list(wfs.contents)[:10]:
        print(f"  {layer_name}")
    
    # دریافت فیچرها به صورت GeoJSON
    response = wfs.getfeature(
        typename='geonode:iran_provinces',
        outputFormat='application/json',
        maxfeatures=5,
    )
    
    geojson = json.loads(response.read())
    
    print(f"\nتعداد فیچرها: {len(geojson['features'])}")
    for feature in geojson['features']:
        props = feature['properties']
        print(f"  {props.get('name_fa', 'N/A')} — جمعیت: {props.get('population', 'N/A')}")
    
    # ذخیره به فایل
    with open('iran_provinces.geojson', 'w', encoding='utf-8') as f:
        json.dump(geojson, f, ensure_ascii=False, indent=2)
    
    print("✅ GeoJSON ذخیره شد")

def csw_search():

    csw = CatalogueServiceWeb(f"{GEONODE_URL}/catalogue/csw")
    
    # جستجوی کلمه‌ای

        outputschema='http://www.isotc211.org/2005/gmd'
    )
    
    print(f"\nنتایج CSW: {csw.results['matches']} رکورد")
    for rec_id, rec in csw.records.items():
        print(f"  {rec_id}: {rec.title}")

"""
مدیریت مجوزها و کاربران در GeoNode
"""

import requests
import json


class GeoNodePermissions:
    """مدیریت مجوزهای GeoNode"""
    
    def __init__(self, base_url: str, username: str, password: str):
        self.base_url = base_url.rstrip('/')
        self.session = requests.Session()
        self.session.auth = (username, password)
    
    def get_permissions(self, resource_pk: int) -> dict:
        """دریافت مجوزهای یک منبع"""
        url = f"{self.base_url}/api/v2/resources/{resource_pk}/permissions/"
        response = self.session.get(url)
        return response.json()
    
    def set_permissions(self, resource_pk: int, 
                        permissions: dict) -> dict:
        """
        تنظیم مجوزهای یک منبع
        
        Parameters
        ----------
        resource_pk : شناسه منبع
        permissions : دیکشنری مجوزها
        
        مثال permissions:
        {
            "users": {
                "admin": ["view", "download", "change", "delete", "manage"],
                "user1": ["view", "download"],
                "user2": ["view"]
            },
            "groups": {
                "gis_team": ["view", "download", "change"],
                "public": ["view"]
            }
        }
        """
        url = f"{self.base_url}/api/v2/resources/{resource_pk}/permissions/"
        response = self.session.put(url, json=permissions)
        
        if response.status_code == 200:
            print(f"✅ مجوزهای منبع {resource_pk} تنظیم شد")
        else:
            print(f"❌ خطا: {response.status_code} — {response.text}")
        
        return response.json()
    
    def make_public(self, resource_pk: int):
        """عمومی کردن منبع"""
        permissions = {
            "users": {
                "AnonymousUser": ["view_resourcebase", "download_resourcebase"],
            },
            "groups": {}
        }
        return self.set_permissions(resource_pk, permissions)
    
    def make_private(self, resource_pk: int, owner: str):
        """خصوصی کردن منبع"""
        permissions = {
            "users": {
                owner: [
                    "view_resourcebase", "download_resourcebase",
                    "change_resourcebase", "delete_resourcebase",
                    "change_resourcebase_permissions"
                ],
            },
            "groups": {}
        }
        return self.set_permissions(resource_pk, permissions)
    
    def share_with_group(self, resource_pk: int, 
                         group_name: str, 
                         level: str = "view"):
        """اشتراک‌گذاری با گروه"""
        current = self.get_permissions(resource_pk)
        
        perm_map = {
            "view": ["view_resourcebase"],
            "download": ["view_resourcebase", "download_resourcebase"],
            "edit": [
                "view_resourcebase", "download_resourcebase",
                "change_resourcebase"
            ],
        }
        
        if 'groups' not in current:
            current['groups'] = {}
        
        current['groups'][group_name] = perm_map.get(level, perm_map["view"])
        return self.set_permissions(resource_pk, current)

class GeoNodeUserManager:
    """مدیریت کاربران GeoNode"""
    
    def __init__(self, base_url: str, username: str, password: str):
        self.base_url = base_url.rstrip('/')
        self.session = requests.Session()
        self.session.auth = (username, password)
    
    def list_users(self, page_size: int = 50) -> list:
        """لیست تمام کاربران"""
        url = f"{self.base_url}/api/v2/users/"
        response = self.session.get(url, params={'page_size': page_size})
        return response.json()
    
    def get_user(self, pk: int) -> dict:
        """دریافت اطلاعات کاربر"""
        url = f"{self.base_url}/api/v2/users/{pk}/"
        response = self.session.get(url)
        return response.json()
    
    def list_groups(self) -> list:
        """لیست گروه‌ها"""
        url = f"{self.base_url}/api/v2/groups/"
        response = self.session.get(url)
        return response.json()
    
    def user_resources(self, username: str) -> dict:
        """لیست منابع یک کاربر"""
        url = f"{self.base_url}/api/v2/resources/"
        params = {'filter{{owner__username}}': username}
        response = self.session.get(url, params=params)
        return response.json()

"""
مدل‌های سفارشی برای افزونه GeoNode
مثال: سیستم گزارش‌دهی مکانی
"""

from django.db import models
from django.contrib.gis.db import models as gis_models
from django.contrib.auth import get_user_model
from geonode.base.models import ResourceBase

User = get_user_model()


class SpatialReport(models.Model):
    """
    گزارش مکانی — اتصال به منابع GeoNode
    """
    
    REPORT_TYPES = (
        ('analysis', 'تحلیل مکانی'),
        ('monitoring', 'پایش'),
        ('assessment', 'ارزیابی'),
        ('survey', 'بررسی میدانی'),
    )
    
    STATUS_CHOICES = (
        ('draft', 'پیش‌نویس'),
        ('review', 'در حال بررسی'),
        ('published', 'منتشرشده'),
        ('archived', 'بایگانی'),
    )
    
    title = models.CharField('عنوان', max_length=255)
    description = models.TextField('توضیحات', blank=True)
    report_type = models.CharField('نوع گزارش', max_length=20, choices=REPORT_TYPES)
    status = models.CharField('وضعیت', max_length=20, choices=STATUS_CHOICES, default='draft')
    
    # ارتباط با منابع GeoNode
    related_datasets = models.ManyToManyField(
        ResourceBase, 
        blank=True, 
        related_name='reports',
        verbose_name='لایه‌های مرتبط'
    )
    
    # فیلد مکانی — محدوده گزارش
    area_of_interest = gis_models.PolygonField(
        'محدوده مورد بررسی', 
        srid=4326, 
        null=True, 
        blank=True
    )
    
    # فیلدهای مدیریتی
    author = models.ForeignKey(User, on_delete=models.CASCADE, verbose_name='نویسنده')
    created_at = models.DateTimeField('تاریخ ایجاد', auto_now_add=True)
    updated_at = models.DateTimeField('تاریخ به‌روزرسانی', auto_now=True)
    
    # فایل پیوست
    attachment = models.FileField('فایل پیوست', upload_to='reports/', blank=True)
    
    class Meta:
        verbose_name = 'گزارش مکانی'
        verbose_name_plural = 'گزارش‌های مکانی'
        ordering = ['-created_at']
    
    def __str__(self):
        return f"{self.title} ({self.get_report_type_display()})"
    
    @property
    def area_hectares(self):
        """مساحت محدوده بر حسب هکتار"""
        if self.area_of_interest:
            # تبدیل به سیستم مختصات متری
            area_m2 = self.area_of_interest.transform(32639, clone=True).area
            return round(area_m2 / 10000, 2)
        return None

"""
API Views برای اپ سفارشی
"""

from rest_framework import viewsets, permissions, filters
from rest_framework.decorators import action
from rest_framework.response import Response
from rest_framework_gis.filters import InBBoxFilter
from django.contrib.gis.geos import GEOSGeometry
from django.contrib.gis.measure import D

from .models import SpatialReport
from .serializers import SpatialReportSerializer


class SpatialReportViewSet(viewsets.ModelViewSet):
    """
    API برای مدیریت گزارش‌های مکانی
    
    GET    /api/reports/          — لیست گزارش‌ها
    POST   /api/reports/          — ایجاد گزارش
    GET    /api/reports/{id}/     — جزئیات
    PUT    /api/reports/{id}/     — به‌روزرسانی
    DELETE /api/reports/{id}/     — حذف
    GET    /api/reports/nearby/   — جستجوی مکانی
    """
    
    queryset = SpatialReport.objects.all()
    serializer_class = SpatialReportSerializer
    permission_classes = [permissions.IsAuthenticatedOrReadOnly]
    filter_backends = [filters.SearchFilter, filters.OrderingFilter, InBBoxFilter]
    search_fields = ['title', 'description']
    ordering_fields = ['created_at', 'title']
    bbox_filter_field = 'area_of_interest'
    
    def perform_create(self, serializer):
        serializer.save(author=self.request.user)
    
    @action(detail=False, methods=['get'])
    def nearby(self, request):
        """
        جستجوی گزارش‌های نزدیک یک نقطه
        
        پارامترها:
            lat: عرض جغرافیایی
            lon: طول جغرافیایی
            radius: شعاع (کیلومتر)
        """
        lat = float(request.query_params.get('lat', 35.7))
        lon = float(request.query_params.get('lon', 51.4))
        radius = float(request.query_params.get('radius', 50))
        
        point = GEOSGeometry(f'POINT({lon} {lat})', srid=4326)
        
        reports = SpatialReport.objects.filter(
            area_of_interest__distance_lte=(point, D(km=radius))
        ).order_by('area_of_interest')
        
        serializer = self.get_serializer(reports, many=True)
        return Response({
            'count': reports.count(),
            'center': {'lat': lat, 'lon': lon},
            'radius_km': radius,
            'results': serializer.data,
        })
    
    @action(detail=False, methods=['get'])
    def stats(self, request):
        """آمار گزارش‌ها"""
        from django.db.models import Count
        
        stats = SpatialReport.objects.values('report_type').annotate(
            count=Count('id')
        )
        
        return Response({
            'total': SpatialReport.objects.count(),
            'by_type': list(stats),
            'by_status': list(
                SpatialReport.objects.values('status').annotate(count=Count('id'))
            ),
        })

health_check.py — بررسی سلامت سیستم 
"""
اسکریپت بررسی سلامت GeoNode
قابل استفاده با cron یا مانیتورینگ خارجی
"""

import requests
import sys
import json
from datetime import datetime


class GeoNodeHealthCheck:
    """بررسی سلامت تمام اجزای GeoNode"""
    
    def __init__(self, base_url: str):
        self.base_url = base_url.rstrip('/')
        self.results = {}
    
    def check_django(self) -> bool:
        """بررسی سلامت Django"""
        try:
            response = requests.get(
                f"{self.base_url}/", 
                timeout=10,
                allow_redirects=True
            )
            ok = response.status_code == 200
            self.results['django'] = {
                'status': 'OK' if ok else 'ERROR',
                'status_code': response.status_code,
                'response_time_ms': response.elapsed.total_seconds() * 1000,
            }
            return ok
        except Exception as e:
            self.results['django'] = {'status': 'DOWN', 'error': str(e)}
            return False
    
    def check_geoserver(self) -> bool:
        """بررسی سلامت GeoServer"""
        try:
            response = requests.get(
                f"{self.base_url}/geoserver/web/",
                timeout=10,
                allow_redirects=True
            )
            ok = response.status_code == 200
            self.results['geoserver'] = {
                'status': 'OK' if ok else 'ERROR',
                'status_code': response.status_code,
                'response_time_ms': response.elapsed.total_seconds() * 1000,
            }
            return ok
        except Exception as e:
            self.results['geoserver'] = {'status': 'DOWN', 'error': str(e)}
            return False
    
    def check_api(self) -> bool:
        """بررسی سلامت API"""
        try:
            response = requests.get(
                f"{self.base_url}/api/v2/datasets/",
                timeout=10,
                params={'page_size': 1}
            )
            ok = response.status_code == 200
            data = response.json() if ok else {}
            self.results['api'] = {
                'status': 'OK' if ok else 'ERROR',
                'total_datasets': data.get('total', 'N/A'),
                'response_time_ms': response.elapsed.total_seconds() * 1000,
            }
            return ok
        except Exception as e:
            self.results['api'] = {'status': 'DOWN', 'error': str(e)}
            return False
    
    def check_wms(self) -> bool:
        """بررسی سلامت WMS"""
        try:
            response = requests.get(
                f"{self.base_url}/geoserver/ows",
                params={
                    'service': 'WMS',
                    'version': '1.1.1',
                    'request': 'GetCapabilities',
                },
                timeout=15
            )
            ok = response.status_code == 200 and 'WMS_Capabilities' in response.text
            self.results['wms'] = {
                'status': 'OK' if ok else 'ERROR',
                'response_time_ms': response.elapsed.total_seconds() * 1000,
            }
            return ok
        except Exception as e:
            self.results['wms'] = {'status': 'DOWN', 'error': str(e)}
            return False
    
    def check_csw(self) -> bool:
        """بررسی سلامت CSW"""
        try:
            response = requests.get(
                f"{self.base_url}/catalogue/csw",
                params={
                    'service': 'CSW',
                    'version': '2.0.2',
                    'request': 'GetCapabilities',
                },
                timeout=10
            )
            ok = response.status_code == 200
            self.results['csw'] = {
                'status': 'OK' if ok else 'ERROR',
                'response_time_ms': response.elapsed.total_seconds() * 1000,
            }
            return ok
        except Exception as e:
            self.results['csw'] = {'status': 'DOWN', 'error': str(e)}
            return False
    
    def run_all(self) -> dict:
        """اجرای تمام بررسی‌ها"""
        checks = {
            'django': self.check_django,
            'geoserver': self.check_geoserver,
            'api': self.check_api,
            'wms': self.check_wms,
            'csw': self.check_csw,
        }
        
        all_ok = True
        for name, check_func in checks.items():
            ok = check_func()
            if not ok:
                all_ok = False
        
        return {
            'timestamp': datetime.now().isoformat(),
            'overall': 'HEALTHY' if all_ok else 'UNHEALTHY',
            'checks': self.results,
        }


if __name__ == "__main__":
    url = sys.argv[1] if len(sys.argv) > 1 else "http://localhost"
    
    checker = GeoNodeHealthCheck(url)
    report = checker.run_all()
    
    print(json.dumps(report, indent=2, ensure_ascii=False))
    
    # خروج با کد خطا اگر ناسالم
    if report['overall'] != 'HEALTHY':
        sys.exit(1)

.github/workflows/deploy.yml 
# ═══════════════════════════════════════════════════════════
# GitHub Actions — GeoNode CI/CD
# ═══════════════════════════════════════════════════════════
name: GeoNode CI/CD

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  # ─── تست ────────────────────────────────────────────────
  test:
    runs-on: ubuntu-latest
    
    services:
      postgres:
        image: postgis/postgis:15-3.3
        env:
          POSTGRES_USER: geonode
          POSTGRES_PASSWORD: geonode
          POSTGRES_DB: geonode_test
        ports:
          - 5432:5432
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5
    
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.10'
          cache: 'pip'
      
      - name: Install dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y libgdal-dev libgeos-dev libproj-dev
          pip install -r requirements.txt
          pip install pytest pytest-django
      
      - name: Run tests
        env:
          DATABASE_URL: postgis://geonode:geonode@localhost:5432/geonode_test
        run: |
          python manage.py test --verbosity=2
      
      - name: Lint check
        run: |
          pip install flake8
          flake8 my_geonode/ --max-line-length=120

  # ─── ساخت Docker Image ──────────────────────────────────
  build:
    needs: test
    runs-on: ubuntu-latest
    if: github.ref == 'refs/heads/main'
    
    steps:
      - uses: actions/checkout@v4
      
      - name: Login to Registry
        uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      
      - name: Build and Push
        uses: docker/build-push-action@v5
        with:
          context: .
          push: true
          tags: |
            ghcr.io/${{ github.repository }}:latest
            ghcr.io/${{ github.repository }}:${{ github.sha }}

  # ─── استقرار ─────────────────────────────────────────────
  deploy:
    needs: build
    runs-on: ubuntu-latest
    if: github.ref == 'refs/heads/main'
    
    steps:
      - name: Deploy to Server
        uses: appleboy/ssh-action@v1
        with:
          host: ${{ secrets.SERVER_HOST }}
          username: ${{ secrets.SERVER_USER }}
          key: ${{ secrets.SSH_PRIVATE_KEY }}
          script: |
            cd /opt/geonode
            docker compose pull
            docker compose up -d --remove-orphans
            docker compose exec -T django python manage.py migrate --noinput
            docker compose exec -T django python manage.py collectstatic --noinput
            echo "✅ Deploy completed at $(date)"

جمع‌بندی و نکات کلیدی

مرور سریع مفاهیم اصلی

🎯

نکات کلیدی

  • GeoNode یک CMS مکانی متن‌باز بر پایه Django + GeoServer + PostGIS
  • Docker ساده‌ترین روش نصب و استقرار است
  • از استانداردهای OGC (WMS, WFS, WCS, CSW) پشتیبانی می‌کند
  • MapStore 2 کلاینت نقشه پیش‌فرض با قابلیت‌های غنی
  • REST API v2 برای تمام عملیات CRUD در دسترس است
  • سیستم مجوزدهی پیشرفته در سطح لایه و نقشه
  • قابلیت سفارشی‌سازی کامل با Django apps
  • پشتیبانی از فرمت‌های متنوع: Shapefile, GeoTIFF, GeoJSON, GeoPackage و ...

🗺️ نقشه راه یادگیری

1
مبتدی: نصب و آشنایی

نصب با Docker → آپلود اولین لایه → ساخت نقشه → مدیریت فراداده

2
متوسط: API و سفارشی‌سازی

استفاده از REST API → اتصال به QGIS → سفارشی‌سازی قالب → استایل‌دهی SLD

3
پیشرفته: توسعه و استقرار

ساخت اپ Django سفارشی → بهینه‌سازی عملکرد → مانیتورینگ → CI/CD → مقیاس‌پذیری
